# IceCream Varanasi 🍦

A modern frontend e-commerce project built for small-scale dessert businesses.

## Features
- Clean and responsive UI
- Product showcase
- Category-based navigation
- Offers and discount section

## Tech Stack
- React.js
- Tailwind CSS
- Vercel Deployment

## Live Demo
https://icecream-varanasi.vercel.app/

## Roadmap 🚀
- Backend integration (Node/Firebase)
- User authentication
- Order management system
- Admin dashboard
- Payment gateway integration

## Vision
To build a reusable e-commerce template for small businesses with minimal setup.

## Status
Actively being improved and expanded.
